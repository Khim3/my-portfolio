## Overview

A Sudoku solver built as a Data Structures & Algorithms project. It models Sudoku as a Constraint Satisfaction Problem (CSP) and extends naive backtracking with the AC-3 arc-consistency algorithm to prune invalid states early, significantly reducing the search space compared to brute-force search.

## Key Features

- **CSP Formulation**: Modeled the board as a constraint satisfaction problem with variables, domains, and the row/column/box uniqueness constraints.
- **AC-3 Arc Consistency**: Implemented the AC-3 algorithm to enforce arc consistency and eliminate impossible candidate values before and during search.
- **Backtracking Search**: Combined constraint propagation with backtracking so the solver only explores consistent partial assignments.
- **Search-Space Reduction**: Pruning invalid states early cuts the number of nodes explored well below naive backtracking, especially on harder puzzles.

## Technologies Used

- **Python**: Core solver implementation.
- **AC-3 / CSP techniques**: Arc-consistency constraint propagation.
- **Backtracking search**: Systematic, constraint-guided exploration.

## Outcome

The solver reliably solves valid Sudoku puzzles while demonstrating how constraint propagation (AC-3) dramatically improves on naive backtracking — a practical illustration of CSP techniques from the DSA course.
