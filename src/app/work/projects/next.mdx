## Overview

A fullstack AI agent platform built with Next.js and LangGraph.js. The system loads tools dynamically through the Model Context Protocol (MCP), runs multi-step tool-calling with a human tool-approval workflow, and persists agent state so conversations can resume across sessions.

## Key Features

- **LangGraph.js Agent Core**: Built the agent runtime on LangGraph.js with multi-step tool calling and a tool-approval workflow that puts a human in the loop before sensitive actions execute.
- **MCP Dynamic Tool Loading**: Integrated MCP for plug-and-play tools — filesystem, HTTP APIs, and custom Python servers — that can be added without changing application code.
- **Streaming Next.js Interface**: Developed a Next.js 16 frontend with Server-Sent Events (SSE) streaming, interactive tool dialogs, and React Query–powered UI updates.
- **Persistent State**: Implemented thread and checkpoint storage with Prisma + PostgreSQL so agent state survives restarts and sessions.
- **Developer-Friendly Setup**: Shipped with Docker Compose, Prisma migrations, environment-based configuration, and an extendable project structure.

## Technologies Used

- **Next.js 16**: Server-rendered React frontend with SSE streaming.
- **LangGraph.js**: Agent orchestration and multi-step tool calling.
- **Model Context Protocol (MCP)**: Dynamic, code-free tool integration.
- **Prisma + PostgreSQL**: Persistent threads and checkpoints.
- **Docker Compose**: Reproducible local development environment.

## Outcome

The platform demonstrates a clean, extendable pattern for building production-style AI agents: tools are added through MCP without code changes, state is durable, and a tool-approval step keeps the human in control of what the agent can do.
